## 🆘 **Troubleshooting**

### **If WebUI doesn't start:**
1. **Check console** - Look for error messages
2. **Verify Python** - Ensure Python is in PATH
3. **Run as admin** - Right-click → "Run as administrator"
4. **Check ports** - Close other applications using port 8501
